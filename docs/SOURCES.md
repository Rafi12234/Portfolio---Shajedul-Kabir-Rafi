## Traceability rules for authors/coding agents

- Attach `evidence` (CV, user, GitHub README, approved client info, external official source) to high-visibility claims.
- For quantitative claims, require methodology, date and owner authorization; no estimate may masquerade as measured impact.
- Link titles to the right version of the artifact; a public GitHub repo URL does not prove it is the running site.
- `sourceUrl` in build data can be a GitHub repository; `liveUrl` must be independently verified and permission-cleared.
- For research, `status` and `doiUrl` are separate fields; never derive either from conference branding alone.
- Always attribute team achievements and collaborators; distinguish individually owned work from shared codebases.
