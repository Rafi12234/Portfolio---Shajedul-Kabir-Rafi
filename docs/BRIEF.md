## Non-negotiable feeling

Cinematic; confident; premium; sophisticated; warm; asymmetrical; typographic; tactile; sharply composed; meticulously animated. Not purple gradients, fake terminals, generic card stacks, stock portraits, overproduced gimmicks or unreadable art-school microtext.

## Distinctive moments

One outstanding photograph-and-type hero; an editorial case-study gallery; a meaningful interaction tied to genuine work if permissions allow; readable scholarly typography; a bold closing title. Novelty must come from personal composition, not random effects.

## Process

Never generate entire website in one session. Design a single section → implement → test → show → revise → owner approves → only then next. Start with header + hero only. An approved written brief is not an approved final visual composition.
