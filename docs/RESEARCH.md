## Critical distinction

A research project, proposal submission, conference submission, conference acceptance, conference presentation, proceedings publication, and IEEE Xplore indexing are *different claims*. The website must keep them separate. A submission must never be displayed under “Publications” as if peer-reviewed or accepted.

## Suggested layout: scholarly editorial register

A spacious research index with 4 explicit status groups: **Accepted & presented**, **Under review / submitted**, **Proposal submitted**, **Ongoing investigation**. Each entry has status, title (if release approved), author list (where known), venue/topic, and one primary approved source link. Use one consistent unambiguous status vocabulary. An optional filter should not collapse status distinctions.

## Citation template (only after proof)

`Authors (in published order). “Title.” Conference/Event, Year. DOI/official proceedings URL.`

For accepted-but-not-indexed work: `Authors. “Title.” Accepted and presented at [conference], [month/year].` Use `accepted and presented` only if confirmation remains current.

## Link policy

Links submitted in a chat are *reference material*, not automatically publication authorization. Avoid checking private docs into a public repo. Place approved source URLs in local typed content only after asking; link to public official conference/DOI pages when available. Do not use URLs that require private permissions as public CTAs.
